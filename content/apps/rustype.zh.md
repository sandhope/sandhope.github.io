Rustype —— 简洁、专注、高效的 Markdown 编辑器

#### 概览

还在找一款干净、专注、高效的 Markdown 编辑器？Rustype 让写作变得简单而愉快。非常适合作家、开发者、博主，以及任何想要一个无干扰环境来创作 Markdown 内容的人。

#### 功能

- **原生极简设计**：干净的界面遵循 macOS 设计规范，没有多余元素，专注内容本身
- **极速性能**：基于 SwiftUI 构建，启动瞬间完成、响应流畅，轻松应对长文档
- **实时预览**：所见即所得的编辑体验，分栏视图中边写边预览
- **深色模式支持**：与 macOS 系统深色模式完美融合，白天黑夜都能舒适写作
- **完整键盘支持**：丰富的键盘快捷键覆盖所有操作，提升写作效率
- **多种导出方式**：保存为 Markdown 文件，或导出为 HTML 格式用于网页发布
- **直观工具栏**：一键按钮快速调用常用 Markdown 格式选项
- **文件管理**：使用熟悉的 macOS 文件对话框，轻松打开、保存和新建文档
- **Markdown 语法支持**：完整支持标题、粗体、斜体、代码块、引用、列表、表格、链接等
- **分栏布局**：编辑器与预览面板并排，写作和校对无缝衔接
- **状态栏信息**：实时显示字数、字符数和行数

#### 数据隐私与安全

- Rustype 是纯离线应用，所有数据都在你的设备本地处理。
- 无需联网，任何文档数据都不会上传到互联网或云服务。
- 我们承诺不收集、不存储、不分享你的任何文档或个人数据。
- 你的所有文字都安全地留在本地设备上。

#### 应用是原生的吗？

是的，使用 Swift 和 SwiftUI 原生开发，性能出色，与 macOS 深度整合。

#### 为什么免费且无广告？

我们相信应该提供纯粹、无干扰的编辑体验。Rustype 旨在帮作家和创作者高效产出优质内容，专注简洁与功能，而不是广告或内购。
