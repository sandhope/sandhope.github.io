XCStrings Crafter —— 原生、AI 驱动的 Xcode 本地化工具

#### 概览

还在找一款强大又易用的本地化工具？XCStrings Crafter 补上了 Xcode 本地化缺失的那一块——一款专为简化 `.xcstrings` 工作流、提升翻译效率而打造的高性能工具。

#### 功能

- **原生 macOS 体验**：遵循 Xcode 官方 UI/UX 设计，同时扩展强大的翻译能力。
- **免费翻译服务**：无缝集成 Apple Translate 和 Google Translate。
- **AI 驱动本地化**：支持 OpenAI、Gemini 和 Grok。API 密钥安全保存在系统钥匙串中，绝不离开本机。
- **与 Xcode 一致的排序**：严格遵循 Xcode 原生排序算法，确保生成的 `.xcstrings` 文件字段顺序与 Xcode 完全一致，消除多余的 Git diff 和合并冲突。
- **智能筛选**：按状态快速筛选条目：已翻译、待审核或未翻译。
- **隐私与安全**：完全在设备本地运行，不上传任何源码或项目数据，确保商业机密和知识产权安全。
- **高性能**：针对海量 `.xcstrings` JSON 结构深度优化，数秒内加载数千条目的文件。
- **实时翻译**：实时预览功能，让翻译即时呈现。
- **直观界面**：基于现代 SwiftUI 设计，易用无需复杂配置。
- **深色模式支持**：完整支持深色模式，任何光线环境下都能舒适工作。

#### 数据隐私与安全

- XCStrings Crafter 是纯离线应用，所有数据都在你的设备本地处理。
- 基础功能无需联网，任何项目数据都不会上传到互联网或云服务。
- API 密钥安全保存在系统钥匙串中，绝不离开你的本机。
- 我们承诺不收集、不存储、不分享你的任何项目数据或个人信息。
- 你的所有本地化工作都安全地留在本地设备上。

#### 应用是原生的吗？

是的，使用 Swift 和 SwiftUI 原生开发，性能出色，与 macOS 深度整合。

#### 为什么是付费应用？

我们希望提供一款功能强大、支持到位的专业本地化工具。付费模式让我们能持续改进应用，并为新版 Xcode 及时更新。
